# Operational Process Improvement & Efficiency Analytics

## Purpose
A portfolio project tailored to the Graduate Engineer Trainee role at Faber Infinite Consulting.
It demonstrates data analysis + Lean/Six Sigma thinking + reporting + dashboarding.

## Tools
Python, Pandas, Excel, Power BI

## Concepts
5S, Kaizen, Lean Management, Six Sigma DMAIC, Pareto Analysis, 5 Why, Fishbone, KPI analysis.

## Run
```bash
pip install pandas numpy openpyxl
python process_analysis.py
python improvement_scenario.py
```

## Important
The dataset is synthetic and the "Before vs After" numbers are a scenario for demonstrating the improvement methodology. Do NOT present them as actual company/client results.

## Interview story
1. I created a structured process dataset.
2. I calculated productivity, defect rate, cycle time, waiting time and downtime.
3. I compared processes and shifts to locate performance gaps.
4. I used Pareto-style prioritization to focus attention.
5. I mapped likely wastes to Lean concepts.
6. I proposed root-cause analysis using 5 Why/Fishbone.
7. I created a dashboard for management-style reporting.
8. I modeled an improvement scenario to show how KPIs could change after corrective actions.
